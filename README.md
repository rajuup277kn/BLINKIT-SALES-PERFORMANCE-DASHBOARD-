📊 Blinkit Sales Analytics Dashboard

🔎 Project Overview

This project is an interactive Blinkit Sales Analytics Dashboard created using Microsoft Power BI. The dashboard analyzes Blinkit's sales data and provides useful business insights through interactive charts, KPIs, and visualizations.

🛠️ Tools & Technologies

- Microsoft Power BI
- Microsoft Excel
- Data Cleaning & Transformation
- DAX
- Data Visualization
- Business Analytics

📈 Key Performance Indicators (KPIs)

- Total Sales: 1.20M
- Average Rating: 3.92
- Average Sales: 140.99
- Number of Items: 9K

📊 Dashboard Analysis

The dashboard provides insights into:

- Sales by Outlet Establishment Year
- Sales by Outlet Size
- Sales by Item Type
- Average Rating by Item Fat Content
- Average Rating by Item Type
- Outlet Type Analysis
- Outlet Location Analysis
- Product Category Performance

🎯 Project Objective

The main objective of this project is to analyze Blinkit's sales data and transform raw data into meaningful business insights using Power BI.

💡 Key Insights

The dashboard helps in understanding:

- Overall sales performance
- Product category performance
- Outlet-wise sales
- Customer rating patterns
- Outlet size and location performance
- Sales trends over different establishment years
